# Supermarket Crowd Analyzer v1.0

A complete AI-powered people-counting and density analysis system using **ESP32-CAM + Flask + YOLOv8 + Heatmap**, all implemented inside a single, easy-to-understand `app.py` backend.

This project captures images from an ESP32-CAM, processes them using YOLOv8 to detect people, generates density heatmaps, and displays everything on a clean dashboard.

---

##  Key Features

###  ESP32-CAM Integration
- Automatic snapshot capture  
- Works over WiFi  

###  Single-File Flask Backend (`app.py`)
Includes:
- YOLOv8 detection  
- Heatmap generation  
- Frame saving  
- HTML template rendering  
- CSS linking  
- Crowd alert logic  
- Dashboard routing  

Everything is inside one professional, well-structured file.

###  Dashboard UI
- Live snapshot display  
- People count  
- Heatmap overlay  
- Crowd-level warnings
